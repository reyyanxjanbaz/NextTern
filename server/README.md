# Backend Services

This directory contains the NextTern backend services.

## Tech Stack

- Node.js
- Express/Fastify
- TypeScript
- Prisma ORM
- PostgreSQL

## Structure

```
src/
├── models/         # Data models
├── services/       # Business logic
├── api/            # Routes, middleware, controllers
└── utils/          # Helpers

prisma/
└── schema.prisma   # Database schema
```

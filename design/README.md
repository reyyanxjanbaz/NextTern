# Design System

This directory contains the NextTern design system.

## Contents

- **tokens/** — Design tokens (colors, typography, spacing, shadows, motion)
- **components/** — Component specifications
- **guidelines/** — Usage documentation

## Principles

Per the Constitution (Article VIII.2):

> Design tokens, spacing rules, and typography are enforced, not optional, and may not be bypassed for convenience.

All UI components MUST use these tokens. Hardcoded values are forbidden.
